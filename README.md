Lending Platform

A production-ready Loan Management System built with Spring Boot that provides secure REST APIs for managing customers, loans, EMI calculations, repayment schedules, and loan lifecycle operations. The project follows clean architecture and enterprise development best practices.

🚀 Features
🔐 JWT Authentication & Authorization
👤 Customer Management
💰 Loan Application & Approval
📊 EMI Calculation
📅 Repayment Schedule Generation
📈 Loan Status Tracking
🗄️ PostgreSQL Database Integration
📖 Swagger/OpenAPI Documentation
✅ Request Validation
⚠️ Global Exception Handling
📝 Logging
🧪 Unit & Integration Testing
🐳 Docker Support (Coming Soon)
